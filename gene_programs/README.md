# Predefined respiratory gene programs

`locked_respiratory_gene_programs.csv` preserves the predefined program list used by the analyses: Complex I assembly (GO:0032981; 30 symbols) and aerobic respiration (GO:0009060; 53 symbols), with 11 shared and 72 unique symbols. The filename is retained for script compatibility. Dataset-specific availability is in `gene_availability_by_dataset.csv`; missing genes were not replaced and programs were not redefined.
